# Avatar: The Last Airbender

## About the Series

*Avatar: The Last Airbender* is an animated fantasy series that follows **Aang**, a young Airbender who must master all four elements to restore balance to the world.

> "Water. Earth. Fire. Air. Long ago, the four nations lived together in harmony."

---

## Main Characters

| Character | Element | Role |
|-----------|---------|------|
| Aang      | Air     | The Avatar |
| Katara    | Water   | Waterbending master |
| Sokka     | None    | Strategist and warrior |
| Toph      | Earth   | Earthbending master |
| Zuko      | Fire    | Prince turned ally |

## Why I Like It

- Great character development
- Funny and emotional moments
- Amazing world-building
  - Four unique nations
  - Different bending styles

## Story Order

1. Book One: Water
2. Book Two: Earth
3. Book Three: Fire

## Fun Code Example

Here is a pretend `Avatar` class:

```python
class Avatar:
    def __init__(self, name):
        self.name = name
        self.elements = ["Air", "Water", "Earth", "Fire"]

    def bend(self, element):
        print(f"{self.name} bends {element}!")

aang = Avatar("Aang")
aang.bend("Air")
```
